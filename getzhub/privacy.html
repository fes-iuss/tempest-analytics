GetzHub privacy policy

Last updated: November 15, 2026

Home Privacy policy

GetzHub is a private home monitoring and control hub that its owner runs on a server in their own home, for their own household. This policy explains what GetzHub does with data it receives from Google.

Who can use GetzHub

Only the owner and members of the owner's household. GetzHub is not offered to the public. The only Google account connected to it is the owner's.

What GetzHub accesses

With the owner's permission, GetzHub uses Google's Smart Device Management API to read these details of the Google Nest thermostat in the owner's home:

  • the thermostat's name and the name of the room it is in
  • room temperature and humidity
  • the heating and cooling mode, the target temperatures, and whether the system is heating or cooling
  • the Eco and fan settings, and whether the thermostat is online

GetzHub can also send the thermostat a new mode or new target temperatures. It does not access any other Google data. It does not read email, contacts, calendar, location, photos or files.

How the data is used

  • To show the thermostat's current state and recent history on the household's private dashboard.
  • To run rules the owner has written, for example to raise an alert or to change a target temperature at a set time.
  • To carry out changes that a member of the household asks for.

The data is not used for advertising, is not used to build profiles, and is not used to train machine-learning or AI models.

Where the data is kept

Thermostat readings are stored in a database on the owner's own server, inside the owner's home. The permission tokens Google issues are stored in a configuration file on the same server. The dashboard is reachable only from inside the home network. Changing anything requires a password; a view-only display for a wall screen is available on the home network without one.

Readings are kept until the owner deletes them. Removing the thermostat from GetzHub deletes its stored readings.

Sharing

GetzHub does not sell this data and does not share it with or transfer it to anyone else.

Alerts the owner sets up, such as a message on the dashboard, a notification to the owner's own phone, or a spoken announcement on the owner's own speakers, contain only the fixed text the owner wrote for that alert.

Google API Services User Data Policy

GetzHub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Withdrawing permission

The owner can withdraw GetzHub's access at any time in their Google Account, as described in Google's help page Manage links between your Google Account and apps from other developers. After that, GetzHub can no longer read or change the thermostat.

Changes and contact

If this policy changes, the new version is published on this page with a new date. Members of the household can ask the owner any question about it. Google's permission screen for GetzHub also shows the developer's contact address.
